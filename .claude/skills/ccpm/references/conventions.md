# Conventions used in this repo

See https://github.com/automazeio/ccpm/blob/main/skill/ccpm/references/conventions.md

- PRDs: `.claude/prds/<feature>.md`
- Epics: `.claude/epics/<feature>/epic.md`
- Tasks: numbered `001.md` then renamed to GitHub issue numbers after sync
- Labels: `epic`, `epic:<name>`, `feature` on epics; `task`, `epic:<name>` on tasks
- Commit format inside epics: `Issue #<N>: <description>`
- Never `--force` git
