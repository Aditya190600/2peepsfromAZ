# Task: Paste session JSON and upload consent

## Why

Operators need to ingest a completed AssemblyAI session without a live call. Upload already exists but lacks an explicit consent checkbox on the Try path; there is no paste-JSON path.

## Description

On `/try`: add a paste-session JSON control that `POST`s to `/v1/analyze-session` using the same session shape as `sampleSessions.js` / `analyze.js`. Add an upload (and paste, if it implies recorded content) **consent checkbox**; disable analyze/upload until checked. Do not store live audio.

## Acceptance Criteria

- [ ] User can paste session JSON and get a real report from `analyze.js`.
- [ ] Invalid JSON shows an error state (not a crash).
- [ ] Upload and paste are disabled until the consent checkbox is checked.
- [ ] Consent copy is honest (recording/upload), not a login.
- [ ] Live / upload / samples remain on `/try` only.

## Technical Details

### Key files
- `client/src/Dashboard.jsx` (Try / lab section)
- `server/checks/analyze.js` (session shape)
- `server/index.js` (`POST /v1/analyze-session`, `POST /v1/transcribe-upload`)
- `client/src/useVoiceAgent.js` (do not change live audio non-storage)

### Done when
Paste and upload both produce reports only after consent is checked.
