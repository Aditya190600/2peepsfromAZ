# Task: Split IA routes and nav

## Why

Session A may still dump Home + lab + report into `Dashboard.jsx`. Product shape (Vanta IA, not paint) needs distinct routes so judges can navigate Home (queue) vs Sessions vs Try without hitting a mic.

## Description

Split the hand-rolled router in `App.jsx` and nav in `Chrome.jsx`:

- `/` Landing
- `/home` KPIs + flagged queue
- `/sessions` list
- `/sessions/:id` report
- `/try` lab (live / upload / samples)

Nav: **Home · Sessions · Try**. Redirect or retire `/dashboard` and `/history` from nav. Reuse Session A stored reports; do not invent a new report renderer.

## Acceptance Criteria

- [ ] All five routes render the intended surface.
- [ ] Nav is Home · Sessions · Try (not Review · History).
- [ ] Get started → `/home`.
- [ ] `/try` holds live/upload/samples; Home does not.
- [ ] `/sessions/:id` shows the stored Report UI from `reportHistory.js` when present.
- [ ] No login. No landing-copy rewrite beyond nav/IA wiring.

## Technical Details

### Key files
- `client/src/App.jsx`
- `client/src/Chrome.jsx`
- `client/src/Dashboard.jsx` (extract Home / Try / Report as needed)
- `client/src/History.jsx`
- `client/src/Landing.jsx`

### Done when
A judge can click through Landing → Home → Sessions → session report → Try without a mic on Home.
