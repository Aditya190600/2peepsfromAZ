# Task: Provider registry and secret store

## Why

Without a single credentials module, STT/LLM/TTS and later SIP will each invent a key-leaking pattern.

## Description

Add `server/providers/credentials.js` (or similar): load from env + gitignored file, never echo secrets in API GET (redact). Registry lists slot + provider id + whether a key is present.

## Acceptance Criteria

- [ ] GET config returns `{ transcriber, model, voice }` ids, not keys
- [ ] PUT/PATCH keys only on server; 400 on empty key
- [ ] `.gitignore` includes the local secrets file

- `server/index.js` routes
